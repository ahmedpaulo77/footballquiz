# من أنا؟ ⚽ Who Am I?

لعبة تقديم **بالعربي والإنجليزي** (زرار لغة فوق بيحوّل الصفحة كلها، ومعاه RTL/LTR أوتوماتيك):
واحد ماسك الموبايل أو اللابتوب بيقرأ السؤال، والناس بتخمّن.
**الإجابة مخفية** في بوكس تحت السؤال، بتفتحها وتقفلها بضغطة، وزرار **«لاعب تاني»**
بيجيب سؤال جديد على طول.

فيه أكتر من لعبة، وبتتنقّل بينهم من فوق:

| اللعبة | السؤال |
| --- | --- |
| ⚽ من أنا؟ | من ٥ لـ٩ تلميحات عن لاعب كورة |
| 🛤️ المسار | مسار أندية لاعب بالترتيب — مين اللاعب؟ |
| 🎯 ريسك | لوحة فئات × ٤ قيم لفريقين — بتظهر ٤ فئات كل جولة، مع «تبديل» وخلية «دبل ×2» |
| 💯 100 نقطة | ١٠ أسئلة × ٤ اختيارات — الفريقين بيوزّعوا ١٠ نقط على الاختيارات |
| 🥉 توب 3 | ٩ أسماء — كل فريق يختار ٣، والإجابة بتظهر بالإحصائيات |
| 👥 تشكيلات المباريات | كارت لكل ماتش مشهور (نهائي أو لأ): الفريقين والسنة والنتيجة — دوس تشوف الـ22 لاعب أساسي |

> **🌊 الكرة الخليجية:** زرار «🌊 الكرة الخليجية» موجود في «المسار» و«100 نقطة» و«توب 3» و«تشكيلات المباريات»،
> بيفصل الأسئلة الخليجية لوحدها (من غير «من أنا؟» و«ريسك»). الأسئلة الخليجية مبتظهرش من غيره،
> والفلتر الخليجي بيظهر اللاعبين والماتشات الخليجية بس (السعودية والإمارات وقطر والكويت والبحرين وعُمان)،
> لحد مستوى متوسط وصعب (مفيش سؤال سهل)، وكله ثنائي اللغة.

> **🧑‍💼 المدربين:** فيه أسئلة «المدربين» الأوروبيين والعالميين اللي بدأوا تدريب بعد ١٩٨٥ (مورينيو، أنشيلوتي، غوارديولا، سيميوني، كلوب، لويس إنريكي…)
> في «المسار» و«ريسك» و«100 نقطة» و«توب 3»، ممزوجة وسط الأسئلة العامة عادي (مفيش زرار أو قسم منفصل).
> المدربين القدام قبل ١٩٨٥ (بيرزوت، فيرغسون، هيتسفيلد…) مستبعدين، والمستوى متوسط وصعب فقط.
> مفيهاش في «من أنا؟» ولا «تشكيلات المباريات».

> بدون صور لاعبين أو شعارات أندية — بيانات نصية فقط، عشان المشروع يبقى آمن قانونيًا.

## طريقة اللعب

1. اختار اللعبة من الأزرار اللي فوق (⚽ من أنا؟ / 🛤️ المسار / 🎯 ريسك / 💯 100 نقطة / 🥉 توب 3 / 👥 تشكيلات المباريات).
2. الصفحة بتفتح على سؤال عشوائي وكل التلميحات **ظاهرة** من البداية:

| اللعبة | اللي بيظهر |
| --- | --- |
| من أنا؟ | كل تلميحات اللاعب (من ٥ لـ٩) مرقّمة بالترتيب |
| المسار | الأندية بالترتيب الزمني (النجمة/«إعارة» معناها اللاعب كان معار) |
| ريسك | ٤ فئات عشوائية × ٤ قيم = ١٦ خلية، وكل خلية سؤال مستقل |
| 100 نقطة | ٤ اختيارات لكل سؤال، وكل فريق يوزّع ١٠ نقط |
| توب 3 | ٩ أسماء، وكل فريق يختار ٣ |
| تشكيلات المباريات | كروت ماتشات مشهورة (نهائيات وغير نهائيات)، ودوس على أي كارت يفتح التشكيل الأساسي |

3. تحتهم **بوكس الإجابة** — مقفول بشكل افتراضي. اضغط عليه تظهر الإجابة، واضغط تاني تختفي.
4. زرار **«لاعب تاني»** بيجيب سؤال جديد فورًا — من غير تحدي يومي، ولا محاولات، ولا انتظار.
5. كل لعبة بتستبعد آخر ١٠ أسئلة ظهرت، فمش هيتكرر نفس السؤال ورا بعضه.
6. زرار اللغة (EN / ع) فوق بيحوّل الصفحة كلها — الواجهة والتلميحات — بين العربي والإنجليزي، وبيقلب اتجاه الصفحة أوتوماتيك وبيحفظ اختيارك.

### طريقة لعب «ريسك»

1. اكتب اسم كل فريق في الكارت بتاعه (أو سيب الاسم الافتراضي).
2. اللوحة بتعرض **٤ فئات عشوائية** من الـ٣٦. لو مش عاجبتك فئة، دوس **«تبديل»** في راسها وهيتبدل بواحدة تانية مش ظاهرة على اللوحة (التبديل قبل البداية بس، ومن غير حد).
3. قبل البداية، الفريق الأول يختار خلية واحدة من الـ١٦ خلية تكون **«دبل ×2»**، وبعدها يدوس «ابدأ اللعبة».
4. الفريق صاحب الدور بيختار خلية من اللوحة (فئة + قيمة).
5. لو صح: بياخد قيمة الخلية، ولو كانت خلية الدبل بياخد **ضعف القيمة أوتوماتيك** (مثال: 20 ← 40). لو غلط: صفر في كل الحالات.
6. الخلية بتتشال، والدور بيروح للفريق التاني. لما الـ١٦ خلية تخلص بتظهر شاشة الفائز (أو التعادل)، و«العب تاني» بتجيب ٤ فئات عشوائية جديدة.

### طريقة لعب «100 نقطة» و«توب 3»

- **100 نقطة:** ١٠ أسئلة، كل سؤال ٤ اختيارات و١٠ نقط. الفريقين بيوزّعوا الـ١٠ نقط على الاختيارات، والحكم بيدخّل التوزيعين، وكل فريق بياخد النقط اللي حطها على الإجابة الصح بس. الأعلى نقاط بعد ١٠ أسئلة يكسب، ولو تعادل فيه سؤال فاصل.
- **توب 3:** ٩ أسماء في كل سؤال، وكل فريق يختار ٣ من غير ما يشوف اختيار التاني. بعد الفريقين الإجابة بتظهر بالإحصائيات: نقطة لكل اسم صح + ٣ بونص لو التلاتة كاملين. ٨ أسئلة، ولو تعادل فيه سؤال فاصل.

### طريقة لعب «تشكيلات المباريات»

1. كل كارت مباراة بيعرض **الفريقين والسنة والنتيجة**، ولو الماتش اتحسم بركلات ترجيح أو وقت إضافي بيظهر ده على الكارت.
2. استخدم فلتر **سهل / متوسط / صعب** أو زرار **«ماتش عشوائي»**.
3. دوس على أي كارت يفتح **التشكيل الأساسي**: ١١ لاعب لكل فريق، مقسّمين حراسة مرمى ودفاع ووسط وهجوم، مع مركز كل لاعب.
4. اللعبة دي **استعراض بقيادة المقدّم** — مفيش نقاط ولا فريقين، ومفيش بدلاء؛ الأساسي بس.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
npm run pages    # build + نسخ النسخة المبنية لجذر الريبو (للنشر)
npm test         # اختبارات منطق اللعبة والتلميحات
```

مفيش أي خدمة خارجية مطلوبة — اللعبة بتشتغل بالكامل في المتصفح.

## إضافة لعبة جديدة (JSON)

كل الأسئلة بقت في ملفات JSON جوه `app/src/data/quizzes/`:

- `who-am-i.json` → لعبة «من أنا؟»
- `paths.json` → لعبة «المسار»
- `risk.json` → لعبة «ريسك»
- `one-question.json` → لعبة «100 نقطة»
- `top-three.json` → لعبة «توب 3»
- `lineups.json` → لعبة «تشكيلات المباريات»

وأي ملف `.json` جديد تحطه هناك بيتحوّل للعبة تلقائيًا — من غير أي كود.
حقل `order` بيحدد ترتيب اللعبة في الأزرار (الأصغر بيظهر الأول).

### لعبة تلميحات (زي «من أنا؟»)

```json
{
  "id": "capitals",
  "title": { "ar": "العواصم", "en": "Capitals" },
  "emoji": "🌍",
  "subtitle": { "ar": "من العاصمة اعرف البلد", "en": "Name the country from its capital" },
  "answerLabel": { "ar": "اسم البلد", "en": "Country name" },
  "nextLabel": { "ar": "سؤال تاني", "en": "Another question" },
  "kind": "clues",
  "order": 3,
  "questions": [
    {
      "id": "cairo",
      "answer": { "ar": "مصر", "en": "Egypt" },
      "clues": [
        { "ar": "أكبر مدينة في العالم العربي.", "en": "The largest city in the Arab world." },
        { "ar": "فيها أقدم جامعة في العالم لسه شغالة.", "en": "Home to the world's oldest still-working university." },
        { "ar": "على ضفاف النيل.", "en": "On the banks of the Nile." }
      ]
    }
  ]
}
```

### لعبة مسار (زي «المسار»)

```json
{
  "id": "paths",
  "title": { "ar": "المسار", "en": "The Path" },
  "emoji": "🛤️",
  "subtitle": { "ar": "الأندية بس… مين اللاعب؟", "en": "Just the clubs… who is the player?" },
  "answerLabel": { "ar": "اسم اللاعب", "en": "Player name" },
  "nextLabel": { "ar": "لاعب تاني", "en": "Another player" },
  "kind": "path",
  "questions": [
    {
      "id": "totti",
      "answer": "Francesco Totti",
      "clubs": ["Roma"],
      "known": 1,
      "loans": [0]
    }
  ]
}
```

### لعبة ريسك (زي «ريسك»)

```json
{
  "id": "risk",
  "title": { "ar": "ريسك", "en": "Risk" },
  "emoji": "🎯",
  "subtitle": { "ar": "لوحة فئات ونقاط… راهن على إجابتك", "en": "A category board… wager on your answer" },
  "answerLabel": { "ar": "الإجابة الصحيحة", "en": "Correct answer" },
  "nextLabel": { "ar": "كمّل", "en": "Continue" },
  "kind": "risk",
  "values": [10, 20, 40, 50],
  "categories": [
    { "id": "world-cup", "title": { "ar": "كأس العالم", "en": "World Cup" }, "emoji": "🏆" }
  ],
  "questions": [
    {
      "id": "world-cup-10",
      "category": "world-cup",
      "value": 10,
      "question": { "ar": "أي منتخب كسب كأس العالم 2022؟", "en": "Which country won the 2022 World Cup?" },
      "answer": { "ar": "الأرجنتين", "en": "Argentina" }
    }
  ]
}
```

- `categories` بتحدد كل الفئات المتاحة، و`values` بتحدد القيم.
- كل سؤال لازم يكون له `category` موجودة في `categories`، و`value` موجودة في `values`.
- اللوحة بتحط الخلية في تقاطع الفئة والقيمة، فالمفروض كل فئة يكون عندها سؤال واحد لكل قيمة.
- كل جولة بتعرض **٤ فئات عشوائية** بس (١٦ خلية)، وكل فئة ليها زرار «تبديل» قبل البداية بيجيب فئة تانية من اللي مش ظاهرة.
- الحساب: صح عادي = `+value`، صح على خلية الدبل = `+2×value`، والغلط = `0` في الحالتين.
- «ريسك» مش محتاجة `clues` ولا `clubs` — عندها `question` و`answer` بس.

### لعبة تشكيلات المباريات (زي «تشكيلات المباريات»)

```json
{
  "id": "lineups",
  "title": { "ar": "تشكيلات المباريات", "en": "Match Lineups" },
  "emoji": "👥",
  "subtitle": { "ar": "الفريقين والسنة والنتيجة", "en": "Teams, year and result" },
  "answerLabel": { "ar": "التشكيلة الأساسية", "en": "Starting lineups" },
  "nextLabel": { "ar": "ماتش تاني", "en": "Another match" },
  "kind": "lineups",
  "order": 6,
  "competitions": [
    { "id": "world-cup", "ar": "كأس العالم", "en": "FIFA World Cup" }
  ],
  "matches": [
    {
      "id": "wc-2022",
      "competition": "world-cup",
      "year": 2022,
      "home": { "ar": "الأرجنتين", "en": "Argentina" },
      "away": { "ar": "فرنسا", "en": "France" },
      "score": "3–3",
      "winner": "home",
      "decidedBy": "penalties",
      "shootout": "4–2",
      "difficulty": "easy",
      "homeLineup": [
        { "pos": "GK", "group": "GK", "ar": "إيميليانو مارتينيز", "en": "Emiliano Martínez" }
      ],
      "awayLineup": [
        { "pos": "GK", "group": "GK", "ar": "هيغو لوريس", "en": "Hugo Lloris" }
      ],
      "source": "https://en.wikipedia.org/wiki/2022_FIFA_World_Cup_final"
    }
  ]
}
```

- `competitions` فيها `id` واسم ثنائي اللغة، وكل ماتش لازم يشاور على `competition` موجود.
- `home` و`away` أسماء الفريقين، و`score` النتيجة النهائية، و`winner` بيكون `home` أو `away`.
- `decidedBy` بيكون `regulation` أو `extra-time` أو `golden-goal` أو `penalties`، و`shootout` مطلوب بس في ركلات الترجيح.
- `difficulty` بيكون `easy` أو `medium` أو `hard` وبيظهر كفلتر في اللعبة.
- كل فريق لازم يكون عنده **١١ لاعب بالظبط** في `homeLineup` و`awayLineup`، و`group` بيكون `GK` أو `DF` أو `MF` أو `FW`، وفريق واحد بس لكل لاعب.
- `source` رابط صفحة الماتش على ويكيبيديا اللي اتأكدت منها التشكيلة.


> **النصوص ثنائية اللغة:** أي نص في الملف يقدر يكون:
> - نص عادي زي `"Roma"` → بيظهر زي ما هو في اللغتين.
> - أو كائن `{ "ar": "...", "en": "..." }` → كل لغة بتشوف نسختها.
>
> لو الكائن ناقص لغة، بياخد المتاح. وعدد `clues` لازم يكون نفسه في العربي والإنجليزي بنفس الترتيب.

| الحقل | إلزامي؟ | إيه ده |
| --- | --- | --- |
| `id` | لا | معرّف السؤال، لو مش موجود بيتولّد تلقائي |
| `answer` | ✅ | الإجابة اللي بتظهر في البوكس المقفول |
| `question` | ✅ (لريسك) | نص سؤال «ريسك» |
| `category` | ✅ (لريسك) | معرّف الفئة اللي الخلية بتقع فيها |
| `value` | ✅ (لريسك) | قيمة الخلية بالنقاط |
| `values` | ✅ (لريسك) | كل قيم اللوحة بالترتيب |
| `categories` | ✅ (لريسك) | فئات اللوحة، كل واحدة ليها `id` و`title` و`emoji` |
| `clues` | ✅ (لتلميحات) | مصفوفة جمل التلميح |
| `labels` | لا | عناوين التلميحات (اختياري) |
| `clubs` | ✅ (لمسار) | أندية اللاعب بالترتيب الزمني |
| `loans` | لا | أرقام الأندية اللي كانت إعارة (تبدأ من ٠) |
| `meta` | لا | سطور تحت الإجابة (الجنسية، المركز…) |
| `known` | لا | نسبة اللي عرفوا اللاعب (من ملفك) |
| `kind` | لا | `clues` أو `path` أو `risk` أو `points` أو `top3` أو `lineups` — بيتحدد تلقائيًا لو مش موجود |
| `order` | لا | ترتيب اللعبة في الأزرار (الأصغر الأول، والافتراضي ٩٩٩) |

> بعد أي إضافة شغّل `npm test` — الاختبارات بتتأكد إن كل سؤال له إجابة بالعربي والإنجليزي،
> وإن كل مسار فيه أندية، وإن عدد التلميحات متساوي في اللغتين، وإن مفيش IDs مكررة،
> وإن لوحة «ريسك» فيها ١٤٤ خلية (٣٦ فئة × ٤ قيم) ومفيش خلية مكررة،
> وإن كل ماتش في «تشكيلات المباريات» عنده ١١ لاعب لكل فريق ومصدر ويكيبيديا.

## تعديل «من أنا؟» وإضافة لاعبين

كل أسئلة «من أنا؟» في ملف واحد:
`app/src/data/quizzes/who-am-i.json` — ٤١ لاعب، وكل لاعب من ٥ لـ٩ تلميحات زي ما هي في آخر نسخة من ملف `Clues`.

كل سؤال شكله كده:

```json
{
  "id": "yarmolenko",
  "answer": { "ar": "أندريه يارمولينكو", "en": "Andriy Yarmolenko" },
  "clues": [
    { "ar": "لعبت في اثنين من الدوريات الخمسة الكبرى: إنجلترا وألمانيا.", "en": "I played in two of Europe's top five leagues: England and Germany." },
    { "ar": "كسبت جائزة أفضل لاعب في بلدي أربع مرات بين 2013 و2017.", "en": "I was named Player of the Year in my country four times between 2013 and 2017." }
  ]
}
```

- **تغيير سؤال موجود:** عدّل `answer` و`clues` بتوعه في مكانه.
- **زيادة تلميح:** ضيف عنصر جديد بنفس الشكل `{ "ar": "...", "en": "..." }` في آخر `clues`.
- **إضافة لاعب جديد:** انسخ أي سؤال، وغيّر `id` (لازم يبقى فريد)، واكتب `answer` بالعربي والإنجليزي، وضيف التلميحات.
- عدد التلميحات لازم يكون **نفسه** في العربي والإنجليزي وبنفس الترتيب — الاختبارات بتتأكد من ده.
- خلي التلميحات **من غير اسم اللاعب نفسه** عشان الإجابة متتحرقش.
- الأندية جوه التلميحات نص عادي، فتقدر تكتبها بالعربي اللي تحبه.

مثال سؤال جديد بالكامل:

```json
{
  "id": "new-player",
  "answer": { "ar": "اسم اللاعب", "en": "Player name" },
  "clues": [
    { "ar": "بدأت مسيرتي سنة 2012 مع نادي كذا.", "en": "I started my career in 2012 with a club in my country." },
    { "ar": "لعبت بعدها في كذا وكذا، وأبرز زمايلي كانوا كذا.", "en": "I later played for several big clubs, alongside some famous teammates." },
    { "ar": "أنا مهاجم من كذا، وعندي 30 سنة، وكسبت كذا.", "en": "I am a forward, I am 30, and I have won several trophies." }
  ]
}
```

### لعبة «المسار»

نفس الفكرة في `app/src/data/quizzes/paths.json`:

- `answer` = اسم اللاعب.
- `clubs` = الأندية بالترتيب الزمني، من أول نادي لآخر نادي.
- `loans` = أرقام الأندية اللي كانت إعارة، وتبدأ من ٠. مثال: لو تاني نادي في القائمة إعارة → `"loans": [1]`.
- عناوين اللعبة (`title` و`subtitle` و`answerLabel` و`nextLabel`) مكتوبة `{ "ar": "...", "en": "..." }`، وأسماء الأندية نص عادي زي ما هي.

بعد أي تعديل: `npm test` وبعدها `npm run pages` واعمل push.

## النشر على GitHub Pages

الموقع: **https://ahmedpaulo77.github.io/footballquiz/**

إعداد Pages عندنا هو **Deploy from a branch → `main` / `(root)`**، يعني GitHub بياخد
الملفات اللي في جذر الريبو زي ما هي. عشان كده النسخة المبنية (`index.html` + `assets/`)
بتتحط في الجذر، أم الكود المصدري فمكانه في `app/`.

### بعد أي تعديل

```bash
npm run pages          # بناء + نسخ الملفات المبنية لجذر الريبو
git add .
git commit -m "update"
git push
```

GitHub بيعيد نشر الموقع تلقائيًا بعد الـ push (خلال دقيقة تقريبًا).

> **مهم:** متعدّلش `index.html` أو `assets/` اللي في الجذر يدويًا — دول ناتج
> `npm run pages` وبيتولّدوا من جديد في كل مرة.

### لو حبيت تستخدم GitHub Actions بدل النشر من البرانش

1. **Settings** → **Pages** → **Build and deployment** → **Source** = **GitHub Actions**.
2. شيل `workflow_dispatch` من `.github/workflows/deploy.yml` وخلّي الـ trigger
   `push: branches: [main]` (أو شغّله يدويًا من تبويب Actions).

> المسارات في `vite.config.js` نسبية (`base: './'`)، فالمشروع بيشتغل على GitHub Pages
> تحت أي اسم ريبو من غير تعديل.
