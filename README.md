# من أنا؟ ⚽

لعبة تقديم عربية (RTL): واحد ماسك الموبايل أو اللابتوب بيقرأ **٣ تلميحات** عن لاعب كورة،
والناس بتخمّن. **الإجابة مخفية** في بوكس تحت التلميحات، بتفتحها وتقفلها بضغطة.
ولو اللاعب مش عاجبك، فيه زرار **«لاعب تاني»** بيجيب لاعب جديد على طول.

> بدون صور لاعبين أو شعارات أندية — بيانات نصية فقط، عشان المشروع يبقى آمن قانونيًا.

---

## طريقة اللعب

1. الصفحة بتفتح على لاعب عشوائي، وتلميحاته الثلاثة **كلها ظاهرة** من البداية.
2. اقرأ التلميحات بالترتيب:

| التلميح | بيقولك إيه |
| --- | --- |
| المحطة الأولى | سنة بداية المسيرة وأول نادي احترافي |
| الزملاء والمسيرة | بقية الأندية + أبرز الزملاء |
| الهوية والإنجازات | المركز والجنسية والعمر + البطولات + اللقب ورقم القميص |

3. تحتهم **بوكس الإجابة** — مقفول بشكل افتراضي. اضغط عليه يظهر اسم اللاعب ونبذة عنه،
   واضغط تاني يختفي تاني.
4. زرار **«لاعب تاني»** بيجيب لاعب جديد فورًا — من غير تحدي يومي، ولا محاولات، ولا انتظار.
5. اللعبة بتستبعد آخر ١٠ لاعبين ظهروا، فمش هيتكرر نفس اللاعب ورا بعضه.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
npm run pages    # build + نسخ النسخة المبنية لجذر الريبو (للنشر)
npm test         # اختبارات منطق اللعبة والتلميحات
```

مفيش أي خدمة خارجية مطلوبة — اللعبة بتشتغل بالكامل في المتصفح.

## هيكل المشروع

كود المشروع كله جوه `app/`، والملفات المبنية بتتحط في جذر الريبو (`index.html` + `assets/`)
عشان GitHub Pages يلاقيها جاهزة للنشر من البرانش.

```
quizes/
├── index.html                  # ⚙️ ملف مبني (بيتولّد من npm run pages) — متعدّلوش يدوي
├── assets/                     # ⚙️ JS/CSS مبنيين (بيتولّدوا من npm run pages)
├── favicon.svg                 # ⚙️ نسخة مبنية من app/public/favicon.svg
├── app/
│   ├── index.html              # قالب الصفحة (المصدر)
│   ├── public/favicon.svg
│   └── src/
│       ├── App.jsx             # اللاعب الحالي + بوكس الإجابة + زرار لاعب تاني
│       ├── main.jsx
│       ├── styles.css          # كل التصميم + الثيمات + الاستجابة
│       ├── data/
│       │   ├── players.js      # بنك اللاعبين (نصي فقط)
│       │   └── profiles.js     # الأندية والزملاء والبطولات للتلميحات
│       ├── lib/
│       │   ├── game.js         # بناء التلميحات + اختيار اللاعب
│       │   ├── game.test.js
│       │   └── storage.js      # الثيم + شاشة الشرح
│       └── components/
│           ├── Header.jsx      # الهيدر وأزرار الشرح والثيم
│           ├── ClueList.jsx    # التلميحات الثلاثة (ظاهرة كلها)
│           ├── AnswerReveal.jsx # بوكس الإجابة المخفي

└── scripts/publish-pages.mjs   # بينسخ dist لجذر الريبو
```

## إضافة لاعبين وتلميحات

### لاعب جديد

افتح `app/src/data/players.js` وضيف عنصر بنفس الشكل:

```js
{
  id: 'unique-id',
  name: 'اسم اللاعب',
  aliases: ['اسم مختصر', 'english name'],
  nationality: 'مصر',
  continent: 'أفريقيا',
  club: 'النادي الأشهر في مسيرته',
  league: 'الدوري المصري',
  position: 'مهاجم', // حارس | مدافع | وسط | مهاجم
  age: 28,           // العمر في 2026
}
```

### بروفايل تلميحات

افتح `app/src/data/profiles.js` وضيف مفتاح بنفس `id`:

```js
'player-id': {
  clubs: ['أول نادي', 'النادي التاني', 'النادي الحالي'], // بالترتيب الزمني
  debut: 2010,                  // سنة أول نادي احترافي
  teammates: ['زميل ١', 'زميل ٢', 'زميل ٣'],
  trophies: ['بطولة ١', 'بطولة ٢', 'بطولة ٣'],
  nickname: 'اللقب',            // اختياري
  shirt: 10,                    // اختياري
},
```

> **مهم:** `club` في `players.js` هو النادي الأشهر مش بالضرورة الحالي — كده البيانات تفضل صح مهما الانتقالات اتغيرت.

اللاعب بيظهر في اللعبة بس لما يكون له بروفايل كامل. بعد الإضافة شغّل `npm test` — فيه اختبارات بتتأكد إن كل اللاعبين بياناتهم كاملة، وإن كل بروفايل مربوط بلاعب موجود، وإن مفيش تلميح بيحرق اسم اللاعب.

## النشر على GitHub Pages

الموقع: **https://ahmedpaulo77.github.io/footballquiz/**

إعداد Pages عندنا هو **Deploy from a branch → `main` / `(root)`**، يعني GitHub بياخد
الملفات اللي في جذر الريبو زي ما هي. عشان كده النسخة المبنية (`index.html` + `assets/`)
بتتحط في الجذر، أم الكود المصدري فمكانه في `app/`.

### بعد أي تعديل

```bash
npm run pages          # بناء + نسخ الملفات المبنية لجذر الريبو
git add .
git commit -m "update"
git push
```

GitHub بيعيد نشر الموقع تلقائيًا بعد الـ push (خلال دقيقة تقريبًا).

> **مهم:** متعدّلش `index.html` أو `assets/` اللي في الجذر يدويًا — دول ناتج
> `npm run pages` وبيتولّدوا من جديد في كل مرة.

### لو حبيت تستخدم GitHub Actions بدل النشر من البرانش

1. **Settings** → **Pages** → **Build and deployment** → **Source** = **GitHub Actions**.
2. شيل `workflow_dispatch` من `.github/workflows/deploy.yml` وخلّي الـ trigger
   `push: branches: [main]` (أو شغّله يدويًا من تبويب Actions).

> المسارات في `vite.config.js` نسبية (`base: './'`)، فالمشروع بيشتغل على GitHub Pages
> تحت أي اسم ريبو من غير تعديل.
