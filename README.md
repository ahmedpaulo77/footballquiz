# من أنا؟ ⚽

لعبة تقديم عربية (RTL): واحد ماسك الموبايل أو اللابتوب بيقرأ السؤال، والناس بتخمّن.
**الإجابة مخفية** في بوكس تحت السؤال، بتفتحها وتقفلها بضغطة، وزرار **«سؤال تاني»**
بيجيب سؤال جديد على طول.

فيه أكتر من لعبة، وبتتنقّل بينهم من فوق:

| اللعبة | السؤال |
| --- | --- |
| ⚽ من أنا؟ | ٣ تلميحات عن لاعب كورة |
| 🛤️ المسار | مسار أندية لاعب بالترتيب — مين اللاعب؟ |

> بدون صور لاعبين أو شعارات أندية — بيانات نصية فقط، عشان المشروع يبقى آمن قانونيًا.

---

## طريقة اللعب

1. اختار اللعبة من الأزرار اللي فوق (⚽ من أنا؟ / 🛤️ المسار).
2. الصفحة بتفتح على سؤال عشوائي وكل التلميحات **ظاهرة** من البداية:

| اللعبة | اللي بيظهر |
| --- | --- |
| من أنا؟ | المحطة الأولى ← الزملاء والمسيرة ← الهوية والإنجازات |
| المسار | الأندية بالترتيب الزمني (النجمة/«إعارة» معناها اللاعب كان معار) |

3. تحتهم **بوكس الإجابة** — مقفول بشكل افتراضي. اضغط عليه تظهر الإجابة، واضغط تاني تختفي.
4. زرار **«لاعب تاني»** بيجيب سؤال جديد فورًا — من غير تحدي يومي، ولا محاولات، ولا انتظار.
5. كل لعبة بتستبعد آخر ١٠ أسئلة ظهرت، فمش هيتكرر نفس السؤال ورا بعضه.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
npm run pages    # build + نسخ النسخة المبنية لجذر الريبو (للنشر)
npm test         # اختبارات منطق اللعبة والتلميحات
```

مفيش أي خدمة خارجية مطلوبة — اللعبة بتشتغل بالكامل في المتصفح.

## إضافة لعبة جديدة (JSON)

أي ملف `.json` تحطه في `app/src/data/quizzes/` بيتحوّل للعبة تلقائيًا — من غير أي كود.

### لعبة تلميحات (زي «من أنا؟»)

```json
{
  "id": "capitals",
  "title": "العواصم",
  "emoji": "🌍",
  "subtitle": "من العاصمة اعرف البلد",
  "answerLabel": "اسم البلد",
  "nextLabel": "سؤال تاني",
  "kind": "clues",
  "questions": [
    {
      "id": "cairo",
      "answer": "مصر",
      "clues": [
        "أكبر مدينة في العالم العربي.",
        "فيها أقدم جامعة في العالم لسه شغالة.",
        "على ضفاف النيل."
      ]
    }
  ]
}
```

### لعبة مسار (زي «المسار»)

```json
{
  "id": "paths",
  "title": "المسار",
  "emoji": "🛤️",
  "subtitle": "الأندية بس… مين اللاعب؟",
  "answerLabel": "اسم اللاعب",
  "nextLabel": "لاعب تاني",
  "kind": "path",
  "questions": [
    {
      "id": "totti",
      "answer": "Francesco Totti",
      "clubs": ["Roma"],
      "known": 1,
      "loans": [0]
    }
  ]
}
```

| الحقل | إلزامي؟ | إيه ده |
| --- | --- | --- |
| `id` | لا | معرّف السؤال، لو مش موجود بيتولّد تلقائي |
| `answer` | ✅ | الإجابة اللي بتظهر في البوكس المقفول |
| `clues` | ✅ (لتلميحات) | مصفوفة جمل التلميح |
| `labels` | لا | عناوين التلميحات (زي «المحطة الأولى») |
| `clubs` | ✅ (لمسار) | أندية اللاعب بالترتيب الزمني |
| `loans` | لا | أرقام الأندية اللي كانت إعارة (تبدأ من ٠) |
| `meta` | لا | سطور تحت الإجابة (الجنسية، المركز…) |
| `known` | لا | نسبة اللي عرفوا اللاعب (من ملفك) |
| `kind` | لا | `clues` أو `path` — بيتحدد تلقائيًا لو مش موجود |

> بعد أي إضافة شغّل `npm test` — الاختبارات بتتأكد إن كل سؤال له إجابة، وإن كل مسار فيه أندية،
> وإن مفيش IDs مكررة.

## إضافة لاعبين وتلميحات

### لاعب جديد

افتح `app/src/data/players.js` وضيف عنصر بنفس الشكل:

```js
{
  id: 'unique-id',
  name: 'اسم اللاعب',
  aliases: ['اسم مختصر', 'english name'],
  nationality: 'مصر',
  continent: 'أفريقيا',
  club: 'النادي الأشهر في مسيرته',
  league: 'الدوري المصري',
  position: 'مهاجم', // حارس | مدافع | وسط | مهاجم
  age: 28,           // العمر في 2026
}
```

### بروفايل تلميحات

افتح `app/src/data/profiles.js` وضيف مفتاح بنفس `id`:

```js
'player-id': {
  clubs: ['أول نادي', 'النادي التاني', 'النادي الحالي'], // بالترتيب الزمني
  debut: 2010,                  // سنة أول نادي احترافي
  teammates: ['زميل ١', 'زميل ٢', 'زميل ٣'],
  trophies: ['بطولة ١', 'بطولة ٢', 'بطولة ٣'],
  nickname: 'اللقب',            // اختياري
  shirt: 10,                    // اختياري
},
```

> **مهم:** `club` في `players.js` هو النادي الأشهر مش بالضرورة الحالي — كده البيانات تفضل صح مهما الانتقالات اتغيرت.

اللاعب بيظهر في اللعبة بس لما يكون له بروفايل كامل. بعد الإضافة شغّل `npm test` — فيه اختبارات بتتأكد إن كل اللاعبين بياناتهم كاملة، وإن كل بروفايل مربوط بلاعب موجود، وإن مفيش تلميح بيحرق اسم اللاعب.

## النشر على GitHub Pages

الموقع: **https://ahmedpaulo77.github.io/footballquiz/**

إعداد Pages عندنا هو **Deploy from a branch → `main` / `(root)`**، يعني GitHub بياخد
الملفات اللي في جذر الريبو زي ما هي. عشان كده النسخة المبنية (`index.html` + `assets/`)
بتتحط في الجذر، أم الكود المصدري فمكانه في `app/`.

### بعد أي تعديل

```bash
npm run pages          # بناء + نسخ الملفات المبنية لجذر الريبو
git add .
git commit -m "update"
git push
```

GitHub بيعيد نشر الموقع تلقائيًا بعد الـ push (خلال دقيقة تقريبًا).

> **مهم:** متعدّلش `index.html` أو `assets/` اللي في الجذر يدويًا — دول ناتج
> `npm run pages` وبيتولّدوا من جديد في كل مرة.

### لو حبيت تستخدم GitHub Actions بدل النشر من البرانش

1. **Settings** → **Pages** → **Build and deployment** → **Source** = **GitHub Actions**.
2. شيل `workflow_dispatch` من `.github/workflows/deploy.yml` وخلّي الـ trigger
   `push: branches: [main]` (أو شغّله يدويًا من تبويب Actions).

> المسارات في `vite.config.js` نسبية (`base: './'`)، فالمشروع بيشتغل على GitHub Pages
> تحت أي اسم ريبو من غير تعديل.
